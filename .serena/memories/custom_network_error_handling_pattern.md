Proyek ini menggunakan pola penanganan error jaringan kustom. Fungsi `load` di server menangkap error dan mengirim flag `dbError: true` ke klien. Ini akan merender halaman error kustom (`src/routes/admin/+error.svelte`) yang secara otomatis mencoba memuat ulang data dengan mekanisme retry. Pemanggilan API sisi klien menggunakan helper `api()` di `src/lib/utils/api.ts` untuk logika retry.
